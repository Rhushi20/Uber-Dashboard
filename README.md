# 🚗 Uber Trip Analysis Dashboard – Power BI Project

Welcome to my **first Power BI dashboard project**, designed to showcase my learning journey in **data analytics and business intelligence**. This interactive report provides an in-depth analysis of Uber trip data, using engaging visuals and insightful DAX calculations.

*Overview Dashboard*

---

## 📈 Project Overview

The **Uber Trip Analysis Dashboard** explores booking behavior, trip metrics, payment methods, vehicle types, and time-based patterns across a one-month dataset. Built in **Power BI Desktop**, this dashboard highlights how data can be transformed into actionable business insights.

---

## 🛠️ Tools & Technologies

- **Power BI Desktop** – for creating interactive dashboards  
- **DAX (Data Analysis Expressions)** – to compute custom KPIs and measures  
- **Power Query** – for data cleaning and transformation  
- **Slicers** – to filter data dynamically by city and date

---

## 📊 Visualizations Used

| Visualization Type       | Description |
|--------------------------|-------------|
| **KPI Cards**            | Track total bookings, revenue, trip distance, time, and value |
| **Donut Charts**         | Display booking value by payment method and trip time (day/night) |
| **Line Charts**          | Show daily booking trends and weekday patterns |
| **Bar Charts**           | Compare bookings by location and vehicle preference |
| **Area Chart**           | Visualize bookings over the course of a day |
| **Heatmap Matrix**       | Show booking intensity by hour and day of the week |
| **Detailed Table View**  | Drill into individual trip records including vehicle, fare, and distance |

---

## 🧠 Key Business Insights

- **UberX** is the most used vehicle type, making up a large portion of total revenue.
- **Uber Pay** is the most popular payment method, used in **67%+** of transactions.
- **Peak booking hours** occur between **9:00 AM and 6:00 PM**, especially on weekends.
- The **most frequent pickup point** is **Penn Station/Madison Sq West**, and the **top drop-off** location is **Upper East Side North**.
